Azure IT Helpdesk Platform

Project Overview

The Azure IT Helpdesk Platform is a cloud-based IT support application designed for a fictional organization.

The platform will allow employees to submit IT support tickets and allow IT technicians to manage, update and resolve those tickets.

Project Objectives

The project is designed to demonstrate practical knowledge of:

- Microsoft Azure
- Cloud infrastructure
- Serverless computing
- Cloud storage
- Identity and access management
- Application security
- Monitoring
- Cost optimization
- Git and GitHub
- Technical documentation

Architecture Goals

The solution will be designed with consideration for:

- Security
- Reliability
- Performance
- Cost optimization
- Operational excellence

Project Approach

The platform will be developed incrementally.

Each Azure component will be deployed, tested and documented before additional components are introduced.

Current Status
